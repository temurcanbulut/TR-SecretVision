# Security and synthetic-only reports

This project is an offline research fixture, not a credential checking service. Never test included values against an external account, bank, identity service or phone network.

Use sample IDs and synthetic minimal reproductions in public reports. If an unexpected real credential or personal record is suspected, do not paste it into a public issue or attach the original private screenshot. Stop distributing that suspected item and contact the actual repository maintainer through an available private channel. This local package has no invented security mailbox or disclosure URL.

Issues about the generator, path validation or annotation semantics can be reported with synthetic fixtures. No third-party service security testing is authorized by this dataset.
