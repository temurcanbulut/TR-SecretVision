# Changelog

## Repository distribution — 2026-10-31

Prepared public-facing English/Turkish documentation, complete metadata and annotations, twenty byte-identical examples, local archive import, ground-truth preview and package validation. The dataset is public on EVREN. No code repository was created or pushed by this preparation. No model training, new export or additional credit spending. Original dataset archives and five frozen renderer sources are unchanged.

## 0.2.0 — original local build

Added developer-security and Turkish personal-data scopes together: ten classes, ten application families and forty compositions; 600 canonical contrastive pairs with sensitive and benign candidate regions; whole-application split assignments; source-identity and payload leakage checks; native small-text slices and dependent downscale/blur companions; full-image prediction scoring with negative alarms, paired context correctness and glyph coverage.

Added explicit invalid-format synthetic identity/IBAN/phone controls and non-cryptographic PEM payloads, source/data freeze, automated ZIP and annotation round trips, primary-source prior-art notes and honest release limitations. The original v0.1 data, archives and frozen OCR source hashes remain unchanged.

This is a new dataset candidate, not a higher score on the old benchmark. No new model performance is claimed. At original build time no live upload or publication was included. Later public EVREN status is recorded in metadata/publication.json. Human verification and v0.2 model-performance evaluation remain unperformed.
